## ✨ Features & Highlights

```yaml
📌 Project Name  : Lav Pandey FAQs
🌐 Live Website   : https://aboutlav.vercel.app
💎 Theme          : Deep Cyber Glow (#0f0f1a + #6c5ce7)
⚡ Tech Stack     : HTML5, CSS3, JavaScript (Vanilla), Bootstrap 5
🔥 Font Styles    : "Covered By Your Grace" (Heading) & "Autour One" (Body)
```

- 🌀 **Material Design 2-Sec Circular Loader** — 3D elevated glowing circular animation
- 🐱 **Floating GIFs Showcase** — 8 hand-curated coding, focus, and lo-fi animated GIFs on side columns
- 🏷️ **Sleek Category Filters** — Custom SVGs with instant filter transitions:
  - 🟣 `All`
  - 🌸 `Personal`
  - 💎 `Education`
  - ⚡ `Tech & Skills`
  - 💼 `Career`
  - 🎮 `Hobbies`
  - 🚀 `Goals`
  - 🤪 `Fun Facts`
- 📱 **100% Mobile & Tablet Responsive** — Adaptive layout with sidebars gracefully collapsing on small screens.
- 🤪 **Custom Funny SVG Favicon** — Unique browser tab icon.
